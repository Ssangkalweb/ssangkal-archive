# 쌍칼 아카이브

삶을 기록하고, 세상을 해부하고, 이야기를 만듭니다.

## 핵심 영역

- 산재와 회복의 기록
- 지식해부학 콘텐츠
- 웹소설과 창작
- AI와 웹 개발 도전
- 쌍칼 광장

## 프로젝트 목표

개인의 경험과 콘텐츠를 한곳에 모으고, 방문자가 읽고 공감하며 다음 콘텐츠로 자연스럽게 이동할 수 있는 모바일 중심 개인 미디어 아카이브를 만듭니다.

## 현재 공개된 콘텐츠

- 삶의 기록 첫 글: `산재가 끝났다고, 회복까지 끝난 건 아니었다`
- 지식해부학 콘텐츠 허브
- 세계·역사·성경·스포츠·경제·산재·웹소설 시리즈 안내
- 유튜브, 티스토리, 문피아, 네이버 웹소설 연결

## 사이트 구조

- `index.html`: 쌍칼 아카이브 첫 화면과 콘텐츠 입구
- `knowledge/index.html`: 지식해부학 콘텐츠 허브
- `knowledge/knowledge.css`: 지식해부학 전용 반응형 스타일
- `life/index.html`: 삶의 기록 목록
- `life/workers-compensation-aftercare.html`: 삶의 기록 첫 글
- `style.css`: 공통 다크 에디토리얼 디자인과 반응형 레이아웃
- `script.js`: 접근 가능한 모바일 메뉴와 연도 보조 처리
- `404.html`: GitHub Pages 프로젝트 경로용 오류 안내
- `.github/scripts/validate_static_site.py`: 구조·내부 링크·SEO·사이트맵 자동검사

별도의 프레임워크나 빌드 과정 없이 시맨틱 HTML, CSS와 순수 JavaScript로 구성합니다.
