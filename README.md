# 쌍칼 아카이브

삶을 기록하고, 세상을 해부하고, 이야기를 만듭니다.

## 핵심 영역

- 산재와 회복의 기록
- 지식해부학 콘텐츠
- 웹소설과 창작
- AI와 웹 개발 도전
- 쌍칼 광장

## 프로젝트 목표

개인의 경험과 콘텐츠를 한곳에 모으고,
방문자가 읽고 공감하고 의견을 남길 수 있는
모바일 중심 개인 미디어 홈페이지를 제작합니다.

## 1.0 기반 구조

별도의 프레임워크나 빌드 과정 없이 시맨틱 HTML, CSS, 순수 JavaScript로 구성합니다.
첫 공개 버전은 아카이브의 네 가지 핵심 입구와 준비 현황, 쌍칼 광장 안내, 소개를 제공하며 실제 콘텐츠와 커뮤니티 기능은 운영 기반을 갖춘 뒤 확장합니다.

- `index.html`: 아카이브 첫 화면과 콘텐츠 입구
- `style.css`: 다크 에디토리얼 디자인과 반응형 레이아웃
- `script.js`: 접근 가능한 모바일 메뉴와 연도 보조 처리
- `404.html`: GitHub Pages 프로젝트 경로용 오류 안내
- `.github/scripts/validate_static_site.py`: 정적 사이트 자동검사
